# Meridian Supply MVP

A lightweight, static B2B wholesale marketplace MVP. The buyer journey is intentionally direct: discover the demo product, then start a pre-filled WhatsApp conversation with the seller.

## Run locally

```bash
python3 -m http.server 8000
```

Open `http://localhost:8000`.

## Images

Place the provided uploads at these exact paths before serving:

- `assets/IMAGE1.jpeg` — homepage hero image
- `assets/IMAGE2.webp` — Polyfix Rapid HV Glue product image
